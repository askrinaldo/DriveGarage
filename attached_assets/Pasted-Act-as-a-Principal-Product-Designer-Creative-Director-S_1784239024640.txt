==================================================
DESIGN GOAL
==================================================

When opening DriveGarage the user should immediately think:

"This looks like an expensive premium automotive platform."

The dashboard should feel handcrafted.

Not AI generated.

Not like an admin panel.

Not like a CRUD application.

==================================================
PRIMARY DASHBOARD EXPERIENCE
==================================================

The dashboard should revolve around the user's vehicles.

If vehicles exist:

The primary vehicle becomes the visual hero.

Large imagery.

Vehicle status.

Quick actions.

Upcoming service.

Latest activity.

Documentation progress.

Vehicle health.

Garage statistics.

If multiple vehicles exist:

Create a beautiful horizontal vehicle gallery.

Users should instantly switch between vehicles.

Think:

Apple Photos

Netflix

Tesla

Porsche

Beautiful horizontal browsing.

If NO vehicles exist:

Do NOT leave an empty dashboard.

Instead create a premium onboarding experience.

Guide the user naturally toward:

• Adding the first vehicle

• Exploring features

• Joining clubs

• Uploading documentation

The empty state should still feel like a finished premium product.
