Jeg ønsker å gjøre plattformen om til et komplett SaaS-system for veteranbiler og klassiske motorsykler.

Målet er å lage Norges beste digitale plattform for lagring av kjøretøyhistorikk, servicehistorikk, restaureringsprosjekter, klubber og dokumentasjon.

TEKNOLOGI

- React
- TypeScript
- Tailwind CSS
- Node.js
- Express
- PostgreSQL
- Prisma ORM
- Stripe
- AWS S3 eller kompatibel objektlagring
- OpenAI API

------------------------------------------------

SUPER ADMIN PANEL

Lag et eget Super Admin-system.

SUPER_ADMIN skal kunne:

BRUKERE

- Se alle brukere
- Søke etter brukere
- Filtrere brukere
- Se siste innlogging
- Se registreringsdato
- Aktivere konto
- Deaktivere konto
- Suspendere konto
- Tilbakestille passord
- Logge inn som bruker (impersonation)

ABONNEMENTER

- Se aktive abonnementer
- Opprette abonnement manuelt
- Endre abonnement
- Oppgradere abonnement
- Nedgradere abonnement
- Gi gratis medlemskap
- Forlenge abonnement
- Se betalingshistorikk

FAKTURERING

- Opprette faktura
- Sende faktura på e-post
- Registrere manuelle betalinger
- Kreditere betalinger
- Se ubetalte fakturaer
- Se inntekter

LAGRING

- Se lagringsforbruk per bruker
- Se lagringsforbruk per klubb
- Se totale filer
- Se totale bilder
- Se totale dokumenter

Eksempel:

Ola Hansen
3.4 GB brukt av 10 GB

Per Olsen
845 MB brukt av 5 GB
