Act as a senior backend security architect and SaaS product lead.

Project: DriveGarage

Important:

* Do not implement broad admin access yet.

   Propose a clear role model:

   Plan how to represent users who should not pay:

* exempt_internal
* exempt_partner
* exempt_test

* optional expiresAt
* reason required
* createdBy required
* createdAt required
* audit log required

Avoid hardcoding permanent exemptions by email in code.

4. Superadmin privacy boundaries
   Define strict rules:

* Superadmin can manage billing status and exemptions.
* Superadmin should see account metadata by default, not full private garage data.
* Viewing a user’s private vehicles/receipts/trips requires an explicit support-access action with reason.
* Every support-access action must be audit logged.
* Receipts/uploads should be especially restricted.
* No silent browsing of private user data.
