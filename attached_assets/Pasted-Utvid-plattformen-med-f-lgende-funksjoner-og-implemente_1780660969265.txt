Utvid plattformen med følgende funksjoner og implementer dem med React, TypeScript, Node.js, PostgreSQL og Prisma.

SUPER ADMIN SYSTEM

Lag et eget Super Admin-panel som kun er tilgjengelig for nettstedets eiere.

Super Admin skal kunne:

- Se alle brukere
- Søke etter brukere
- Se alle klubber
- Se alle kjøretøy
- Se alle abonnementer
- Se alle betalinger
- Se systemlogger
- Se innsendte forbedringsforslag
- Se statistikk over aktivitet

Super Admin skal kunne:

- Redigere brukere
- Nullstille passord
- Aktivere/deaktivere kontoer
- Hjelpe brukere med feil
- Flytte eierskap av klubber
- Suspendere brukere
- Suspendere klubber
- Sende meldinger til brukere
- Sende meldinger til alle medlemmer

Lag rolle:

SUPER_ADMIN

Denne rollen skal ha tilgang til absolutt alt i systemet.

- Opprette supportsaker

- Rapportere feil
- Be om hjelp

Super Admin skal kunne:

- Se alle saker
- Svare på saker
- Lukke saker
- Markere saker som løst

AI-HJELPEBOT

Lag en AI-chatbot nederst til høyre på alle sider.

Funksjoner:

- Hjelpe brukere med nettsiden
- Forklare funksjoner
- Hjelpe med registrering av kjøretøy
- Hjelpe med klubber
- Hjelpe med abonnement

Chatvindu:

- Flytende knapp nederst til høyre
- Åpnes som popup
- Mobilvennlig
- Mørk modus

Lag støtte for OpenAI API.

Hvis AI ikke kan hjelpe:

- Opprett supportsak automatisk

------------------------------------------------

FORBEDRINGSFORSLAG

Lag egen funksjon:

"Send forbedringsforslag"

Brukere kan sende:

- Ideer
- Feilmeldinger
- Ønsker om nye funksjoner

Når forslag sendes:

- Lagres i databasen
- Vises i Super Admin-panel
- Sendes til administrator e-post

Felter:

- Tittel
- Beskrivelse
- Prioritet
- Bruker-ID
- Dato

------------------------------------------------

TEMA OG FARGER

La brukere velge egne temaer.

Standardtema:
- Mørkt

Velgbare farger:

- Blå
- Rød
- Grønn
- Oransje
- Gul
- Lilla
- Grå

Brukere skal kunne:

- Endre hovedfarge
- Endre aksentfarge
- Bytte mellom lys og mørk modus

Lagre valg i databasen.

Temaet skal lastes automatisk ved innlogging.
