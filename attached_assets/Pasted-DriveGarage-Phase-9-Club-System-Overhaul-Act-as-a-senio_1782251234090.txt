DriveGarage Phase 9 – Club System Overhaul

Act as a senior SaaS architect, backend security engineer, and community platform designer.

Project: DriveGarage

Goal:
Transform the current Club feature into a secure, scalable club/community system suitable for automotive clubs, enthusiast groups, and local organizations.

Current issues:

Non-members can still access too much information.
Unauthorized users can see actions they should never see.
Club permissions are inconsistent.
Club privacy is unclear.
Club pages feel unfinished.
Club ownership/admin/member roles need stronger enforcement.
Clubs should function more like Facebook Groups for car enthusiasts.

Important:

Backend authorization is the source of truth.
Frontend must only display actions the user can perform.
No breaking changes to existing clubs unless required for security.
Deliver a complete audit and implementation plan before making destructive schema changes.
1. Club Visibility Model

Add support for:

Public Club

Visible in club discovery.

Non-members may see:

Club name
Description
Banner/logo
Location
Member count
Vehicle count
Upcoming public events

Non-members may NOT see:

Member list
Garage details
Forum posts
Internal events
Files
Documents

Show:

"Bli med i klubben"

instead of member content.

Private Club

Visible only if:

Member
Invited
Owner/Admin

Non-members may only see:

Club name
Short description
Privacy badge

Everything else hidden.

2. Club Roles

Support:

Owner

Can:

Edit club
Delete club
Promote/demote admins
Remove members
Change privacy
Manage invitations
Manage events
Admin

Can:

Approve requests
Invite users
Remove members
Manage events
Moderate forum

Cannot:

Delete club
Remove owner
Transfer ownership
Member

Can:

View member content
Participate in forum
Upload vehicles to club garage
Join events

Cannot:

Remove users
Edit club settings
Delete club
Non-member

Can only access what visibility rules allow.

6. Club Forum
